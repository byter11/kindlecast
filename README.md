**KindleCast** converts EPUB, MOBI, and DOCX files into Kindle-friendly formats and hosts them on your local network. Simply open the generated link on your Kindle's web browser, and your book is ready to read.

## Features
- One-Tap Conversion: Effortlessly convert ebooks and start hosting them instantly.
- Works Completely Offline: Your books stay on your device.
- Wireless Transfer: Download converted books directly using the Kindle web browser.
- Broad Format Support: Works with EPUB, MOBI, and DOCX files.
- Seamless Integration: Share ebooks directly from other apps to KindleCast for quick processing.
- Modern Design: Beautiful Material You interface with dynamic theming.

## Getting Started

### Prerequisites

- Android Studio Hedgehog or newer
- Android device or emulator (API 33+)

### Building

Clone the repository and open in Android Studio:

```sh
git clone https://github.com/yourusername/kindlecast.git
cd kindlecast
```

Build and run using Android Studio or:

```sh
./gradlew assembleDebug
```

Uses Calibre under the hood: https://calibre-ebook.com/

## Dependencies

- AndroidX Core, AppCompat
- Material Components
- [Chaquopy](https://chaquo.com/)
